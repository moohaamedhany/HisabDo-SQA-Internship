## 🐞 API Results & Bugs Found (DummyJSON)
14 of 16 API test cases passed. 2 genuine bugs were found during actual Postman execution:

| Bug ID | Title | Expected | Actual | Severity | Priority | Status |
|---|---|---|---|---|---|---|
| BUG_001 | Server accepts a product even though the request body is empty | 400 Bad Request | 201 Created, product added with no data | Medium | Medium | Open |
| BUG_002 | Server accepts a product even though the price has an invalid data type | 400 Bad Request | 201 Created, product added with an invalid price type | Medium | Medium | Open |

Both point to the same root cause: no server-side input validation on `POST /products/add`.
