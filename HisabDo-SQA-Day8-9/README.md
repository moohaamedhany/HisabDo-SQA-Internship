📌 Project Overview

This repository contains the QA documentation and test execution work completed for the HisabDo Capstone Project – Day 8 & Day 9.

The objective was to analyze the HisabDo product, prepare a professional QA Test Plan, design executable test cases for the website and Android application, execute available test cases, and document confirmed defects.
